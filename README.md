# Soleil frontend

This is the Soleil marketing frontend, built with React, TypeScript, and Vite. It does not connect to the trading application yet.

## Run locally

```sh
npm install
npm run dev
```

Open http://127.0.0.1:8765/. Run `npm run build` to type-check and create a production build in `dist/`.

The page sections are in `src/App.tsx`, the footer is in `src/components/ui/footer-16.tsx`, and styles are in `src/styles.css`. Images are served from `public/assets/`.
